# Agents Catalog

Agents are persona definitions that compose multiple skills into a focused role. When you use an agent, Claude takes on that identity and applies the relevant skills together.

All agents auto-load when the swishbot plugin is installed — no per-agent install step. Invoke an agent by asking Claude to "act as the analytics-engineer agent" or by selecting one from `/agents`.
